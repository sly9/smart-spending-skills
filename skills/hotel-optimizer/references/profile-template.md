# Traveler profile template / 个人档案模板（酒店）

The skill needs this information about the traveler. Fill in what applies and leave the rest blank. If you already have a profile for the smart-shopping-optimizer skill, add these sections to it instead of starting a new one. Save it wherever you like (a private repo, a note, a doc). Then point Claude at it with a line in your CLAUDE.md or Claude account preferences, for example:

> My cards, memberships, hotel status and spending rules are in `<repo / file / doc>`. Read them before any shopping, booking or card decision.

**Never put full card numbers, CVVs, passwords or account logins here.** Card names, the last 4 digits and the last digits of member numbers are enough.
