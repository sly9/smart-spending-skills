# Shopper profile template / 个人档案模板

The skill needs this information about the shopper. Fill in what applies and leave the rest blank. Save it wherever you like (a private repo, a note, a doc). Then point Claude at it with a line in your CLAUDE.md or Claude account preferences, for example:

> My cards, memberships and spending rules are in `<repo / file / doc>`. Read them before any shopping or card decision.

**Never put full card numbers, CVVs, passwords or account logins here.** Card names and the last 4 digits are enough.
